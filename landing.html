How Task E Transforms Speech in 4 Steps

No external language model API calls. No waiting for round-trip server requests. Everything is executed through deterministic regular expression heuristics and temporal resolvers right on the client machine.

1

Continuous Audio Capture

Direct integration with the browser's native Web Speech API stream. Handles interim speech tokens with zero audio data transmitted to third-party recording servers.

webkitSpeechRecognition()
2

Smart Clause Splitting

Context-aware lookahead regex identifies true task boundaries (e.g. coordinating conjunctions followed by imperative action verbs) while protecting noun-pair conjunctions.

/(?:(?:\band\b|\bthen\b)(?=\s+(?:call|buy|...)))/
3

Temporal & Priority Extraction

Resolves relative date words like "tomorrow evening", "by Friday", and "in 2 hours" into ISO timestamps, and scans for urgency tokens to grade priorities.

extractDueDate() + extractPriority()
4

Local-First Storage & PWA

Writes tasks directly to localStorage schema v2. Cache-first Service Worker guarantees offline availability and instantaneous app launch on desktop and mobile.

localStorage + ServiceWorker (sw.js)

Got Questions?

Frequently Asked Questions

Everything you need to know about Task E, privacy, browser compatibility, and local-first data storage.

Does Task E send my voice or tasks to a remote server?
No! Task E is strictly local-first. Speech recognition utilizes your browser's native Web Speech API implementation, and the NLP clause splitting, date calculation, and task sorting are executed entirely within client-side JavaScript. Your tasks remain securely stored in your browser's localStorage.
Which browsers support native voice dictation?
Google Chrome (Desktop & Android), Microsoft Edge, and Safari (iOS 14.5+ & macOS) fully support the Web Speech API. If you use a browser like Firefox where the Web Speech API is currently unavailable, Task E automatically provides an integrated manual text drawer that runs through the exact same NLP parser.
How does Google Authentication work without a backend?
Task E connects directly to Google Identity Services (GIS). When you sign in, Google returns a cryptographically signed OpenID Connect JWT ID token. Task E decodes this token in the browser to extract your profile name, email, and avatar for personalized task attribution without requiring any server database.
Can I install Task E on my mobile phone home screen?
Yes! On iOS Safari, tap the Share icon and select "Add to Home Screen". On Chrome for Android, tap the menu and select "Install App". It launches as a full-screen, standalone application with safe-area spacing and offline capabilities.
Can I export my tasks to other apps or backups?
Yes! The Export & Backup modal allows you to copy formatted plain text checklists to your clipboard, download a .txt file, or export a complete .json backup. You can also restore past JSON backups anytime.
